## 典型场景规则复核

| 场景 | 规则导向 |
| --- | --- |
| 上下文已有 AGENTS.md、目标路径及所需正文 | 直接使用；不重读 AGENTS.md、地图或目录 reference |
| 只知道业务地图路径，不知道目标领域 | 只补读相关地图部分，再读取缺失的目标正文；不把已知路径当作已知内容 |
| 已知自定义目录，继续实施或引用场景 | 使用已确定的根和入口，不回到默认 docs 目录 |
| 首次落位场景和实施文档 | 由 impl-gov 建立所需文档，场景与实施同级，实际入口写入 AGENTS.md，不调用 doc-gov |
| 建立或调整设计文档入口 | 由 doc-gov 融入现有目录并更新自身常驻条目，保留其他 skill 和项目专项声明 |
| 文件变更、冲突或上下文丢失 | 只刷新受影响或缺失部分；重复触发本身不构成重读理由 |
| 工程关通过且用户关规则已在上下文 | 自动准备验收包，无需重读规则；包未就绪不能让用户签收 |
