# 维护常驻治理声明

只在用户要求启用治理、切换治理类型或更新常驻入口时读取。

## 写入前定位

1. 读取当前范围现有的 `AGENTS.md`，保留所有无关指令。
2. 确认用户已经决定治理类型。
3. 定位项目实际入口，不依据推荐目录猜测路径。

导航型需要确认项目导航。设计型需要确认业务地图、技术地图、ADR、活动实施契约和归档实施契约入口。缺少设计型基础入口时，返回 `SKILL.md` 叠加“建立设计文档体系”任务包。

## 合并声明

- 导航型读取 `assets/AGENTS.navigation.fragment.md`。
- 设计型读取 `assets/AGENTS.design.fragment.md`。
- 替换所有占位符后合并到现有 `AGENTS.md`。
- 切换类型时替换完整的 `## 文档治理` 区块，不叠加两种片段。
- 片段只提供治理类型、实际入口和 skill 触发边界；任务规则由 `SKILL.md` 按当前任务选择 reference，不写入常驻声明。

## 验证

- 没有遗留占位符。
- 所有声明入口真实存在。
- 根 `AGENTS.md` 的通用治理声明只保留治理类型、稳定发现入口和 skill 触发边界，没有复制完整文档拓扑或任务细则。
- 启用治理没有被解释为获得全局审计授权。
