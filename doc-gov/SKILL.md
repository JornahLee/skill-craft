# 治理项目文档

项目实际文档地图常驻 `AGENTS.md`，可直接用于定位，不依赖先触发本 skill。本 skill 提供文档建立与维护规则，不因项目采用某种治理类型就加载整套治理知识。

## 开始任务

1. 先用当前上下文已有的治理类型、目录职责、文档入口和已读内容；目标文档已知时直接处理，不重走 `AGENTS.md → 地图 → 文档`。
2. 治理类型或入口缺失时，才补读 `AGENTS.md` 相关部分。若仍无治理类型且本次确需确定，再读取 [governance-selection.md](references/governance-selection.md)。
3. 下表只用于选择当前动作缺失的维护规则。上下文已含所需规则时跳过 reference；普通定位不读取目录规范、启用流程或完整设计骨架。
4. 目标归属或关系不明时，才局部读取对应地图；需要的正文不在上下文时，才读取目标文档相关部分。只沿明确关系或代码证据扩大范围。

skill 触发、重复触发或阶段切换都不是重读理由。只有上下文丢失、出现文件变更或冲突证据、用户要求核验时，才刷新受影响部分。入口已知不等于正文已读，不得把导航信息当作业务或技术事实。

## 全局约束

- 默认局部定位并渐进读取；不得为求稳妥扫描全部文档或代码。
- 同一事实只保留一个权威定义；摘要和实现投影必须可追溯到权威来源。
- 发现多个权威来源、语义冲突或代码越过声明边界时，列出证据和待决定问题，不静默选择版本或扩大范围。
- 用户要求建立或调整本 skill 职责内的文档结构时，将目录职责、实际入口和读取时机同步到 `AGENTS.md`，保留其他 skill 的声明；普通触发不改常驻指令、不切换治理类型、不执行全局审计。
- 本 skill 管理项目导航、业务设计、技术设计和 ADR；可引用实施与用户场景文档，但不规定它们的目录或代替所属 skill 初始化。
- 只把本次任务直接需要的 reference 读入上下文；项目治理类型不是完整加载某组 reference 的理由。
